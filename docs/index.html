ข้อจำกัด ข้อมูลมีเฉพาะเที่ยวเรือที่ออกจริง ยังไม่มีบันทึกการงดออกเรือ จึงยังไม่ควรสร้างโมเดลจำแนก "ควร/ไม่ควรออกเรือ" · ฟีเจอร์ใช้เฉพาะข้อมูลก่อนวันออกเรือเพื่อกัน data leakage · พยากรณ์ใน weather_forcasting เพิ่งเริ่มเก็บ ต้องสะสมหลายเดือนก่อนนำมาเป็นฟีเจอร์

Collections ใน MongoDB

—

เส้นทางข้อมูล

จาก MongoDB ในเครื่อง ถึงหน้าเว็บนี้

1. Open-Meteo → MongoDB

src/09_fetch_forecast.py ดึงพยากรณ์ 7 วันทุกเช้า (Task Scheduler) เก็บทุกรอบใน weather_forcasting

2. MongoDB → JSON

src/11_export_web_data.py สรุปข้อมูลเป็นไฟล์ใน docs/data/ (อ่านอย่างเดียว ตัดข้อมูลระบุตัวบุคคลออก)

3. JSON → GitHub Pages

commit และ push โฟลเดอร์ docs/ หน้าเว็บนี้อ่าน JSON ในเบราว์เซอร์ ไม่ได้เชื่อม MongoDB โดยตรง

ข้อมูลที่ไม่เผยแพร่บนเว็บ ชื่อกัปตัน ชื่อเรือ ชื่อบริษัทลูกค้า และลิงก์ไฟล์รูปภาพ (catch_images) · สำหรับการค้นข้อมูลสดในเครื่อง ใช้ FastAPI (backend/main.py) กับ frontend/index.html
